# Gazetteer data

`countries.json` and `usa-states.json` are copies of
[`public/gazetteer/countries.json`](https://github.com/grafana/grafana/blob/main/public/gazetteer/countries.json) and
[`public/gazetteer/usa-states.json`](https://github.com/grafana/grafana/blob/main/public/gazetteer/usa-states.json)
in `grafana/grafana`. The files are not changed.

License: Grafana is AGPL-3.0, and this repository is AGPL-3.0-only (see `LICENSE`). Thus the copy is allowed.
The country and state coordinates come from the
[worldmap-panel](https://github.com/grafana/worldmap-panel/blob/master/src/data/countries.json) data set.
